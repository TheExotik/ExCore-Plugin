# ExCore-Plugin
- A full complete library of mechanics for all The_Exotik plugins and Others Addons. 
- My only goal with this library is: **Be able to create a whole vanilla modpack**. _"What you mean with a vanilla modpack?"_... Well thats simple:
- I play minecraft for a _long time_ (back to 1.5.2 minecraft version) and i always had a start PC, that means most of time i cannot play big modpacks or something like...
- So when i started this project, my goal is to make possible to add into **Vanilla Minecraft** the same (or pretty close) experience of most of modpacks had, like custom machines, items, powers, monsters... and go on.

- Here you will see most of mechanics pretty closed to most rated mods, so you and your friends can play some **"Vanilla Mods"** without actually had theses mods installed, so no worries with your low start pc, the **high process** runs inside server host.

# How can i create a Addon with this library?
- Well, as i said, this project still very new, so theres many of things to improve/change.
- For now, **You will not be able to create a addon** 
- **BUT**
- You can send a "[Suggestion](https://github.com/TheExotik/ExCore-Plugin/issues)" via issues pages, so i can look at.
